# Changelog

## 0.6.1 — 2026-07-20

- 节点指纹升级为版本化稳定 SHA-256 指纹；
- 支持忽略节点名称、字段顺序、域名大小写、IPv6 等价写法和明确默认空值；
- 同一批导入、不同批次导入和本地历史工作区统一去重；
- 启动时自动迁移旧指纹并删除旧工作区重复项，保留最早记录；
- 补充等价节点、不同凭据、不同传输和 IPv6 规范化回归测试；
- 从导入到导出重新执行源码、格式、依赖和打包检查。

## 0.6.0 — 2026-07-20

- 使用用户提供的树林图片作为全局自适应背景，并增加可读性遮罩和半透明卡片；
- 可用节点支持点击进入详细检测页面；
- 在同一个隔离节点实例中分别检测 IPv4-only 和 IPv6-only 出口；
- 增加国家、城市、时区、ASN、机构、ISP、CIDR、反向域名和网络类型字段；
- 增加 IPinfo 和 AbuseIPDB 可选数据源；
- API 密钥通过 Windows DPAPI 加密存储，不进入普通设置和导出；
- 增加透明的风险/参考纯净度计算与“数据不足”状态；
- 最多保存 20 条 IPv4/IPv6 出口历史并识别地址轮换；
- 增加不包含节点连接凭据的 JSON 安全报告；
- 本地数据 schema 升级到版本 2，并兼容读取 v0.5.0 数据。

## 0.5.0 — 2026-07-19

- 支持网页乱文本自动筛选、多格式节点导入；
- 接入独立 sing-box 可用性检测、真实出口查询、自动命名和 Karing 配置导出。
